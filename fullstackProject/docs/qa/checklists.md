# Чек-листы: CineBooking

Быстрая проходка перед релизом и после изменений в соответствующей области.
Полные пошаговые проверки — в [test-cases.md](test-cases.md).

Легенда: [ ] — не проверено · [x] — пройдено · ✋ — требует ручного глаза/стенда

## CL-1. Каталог фильмов (Home)

- [ ] `GET /api/movies` отдаёт 6 фильмов с постерами, жанрами, ценой и временем сеанса
- [ ] первый заход — бейдж источника «БД», повторный в течение 60 c — «из кэша»
- [ ] через 60 c (TTL Redis) снова «БД»
- [ ] карточка фильма ведёт в модалку брони с этим фильмом

## CL-2. Карта зала и выбор мест

- [ ] `GET /api/movies/:id/seats`: сетка 8×10, занятые места подсвечены
- [ ] занятые = места существующих броней (сверить с `/api/bookings`)
- [ ] клик по свободному месту выбирает, повторный — снимает выбор
- [ ] счётчик «свободно» сходится: 80 − занятые
- [ ] ✋ модалка не даёт отправить бронь без мест и без имени

## CL-3. Создание брони

- [ ] `POST /api/bookings` возвращает 201, статус `PENDING`, сумма = цена × места
- [ ] неверный формат места (`5`, `9-1`, `1-11`) → 400
- [ ] пустой список мест / не массив / 9+ мест / имя из 1 символа / не-uuid `movieId` → 400
- [ ] несуществующий фильм → 404
- [ ] бронь занятого места → 409 со списком `seatsTaken`
- [ ] после 409 свободные места из отклонённого запроса остались свободными

## CL-4. Обработка воркером (статусы)

- [ ] через 1,2–2,8 c `PENDING` → `CONFIRMED` (~90%) или `FAILED` (~10%)
- [ ] у вердикта есть сообщение, `processedBy = go-worker-1`, `processedAt`
- [ ] `FAILED` освобождает места — их можно забронировать снова
- [ ] `GET /api/bookings/stats` сходится с фактическим списком

## CL-5. Отмена брони (сага)

- [ ] кнопка «Отменить» есть только у `CONFIRMED`-броней
- [ ] отмена → 200, статус `CANCELLING`, места пока заняты
- [ ] повторная отмена (двойной клик) → 409 с текущим статусом
- [ ] отмена `PENDING`/`CANCELLED` → 409; несуществующей брони → 404
- [ ] возврат прошёл (~90%): `CANCELLED`, места снова в продаже, сообщение про возврат
- [ ] банк отказал: бронь вернулась в `CONFIRMED`, места держатся, сообщение об отказе
- [ ] плитки статистики «возвраты»/«отменено» обновляются

## CL-14. Лист ожидания (waitlist)

- [ ] модалка полного сеанса: вместо сетки мест — CTA «встать в очередь», после join — позиция и «выйти»
- [ ] гварды join: без токена 401, не-uuid 400, незнакомый сеанс 404, неполный зал 409 `sessionNotFull`, начавшийся 410 `sessionPassed`, дубль 409 `waitlistAlready`
- [ ] leave: 204, повторный — 404 `waitlistEntryNotFound`; повторный join — в конец очереди
- [ ] /my: блок «лист ожидания» с позициями; NOTIFIED — баннер «место освободилось»; LEFT и прошедшие сеансы скрыты
- [ ] освобождение места любой из 4 точек (отмена неоплаченной / EXPIRED / FAILED / возврат) уведомляет голову: SSE `waitlist` + письмо в `:18082` (kind `waitlist_seat`, ссылка `?movie=`)
- [ ] место не резервируется: уведомлённый выигрывает бронью; create гасит его запись, следующее освобождение — следующему
- [ ] ✋ в демо на Pages: сеанс «КиноКлуб» — сид-аншлаг, очередь живёт в движке, NOTIFIED-переходы без сети
